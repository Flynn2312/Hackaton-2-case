## 📌 1. Производственная задача и концепция решения
Автомобильное производство Allur включает взаимосвязанную технологическую цепочку:
$$\text{Склад комплектующих} \longrightarrow \text{Сварка} \longrightarrow \text{Окраска} \longrightarrow \text{Сборка} \longrightarrow \text{Контроль качества (ОТК)} \longrightarrow \text{Склад ГП}$$

**Ключевые вызовы производства:**
1. **Аварийные простои оборудования:** критический риск остановки главного Конвейера-03 сборки (инцидент 02.10 — обрыв цепи на 55 минут при суточном нормативе завода ≤60 мин).
2. **Всплеск брака окрасочного цеха:** рост дефектов ЛКП в Камере-02 до 5.2% (при нормативе завода ≤2.0%) из-за раскалибровки сушильной печи после замены фильтра.
3. **Рассинхронизация потока:** снижение OEE сварки до 81.0% вызвало дефицит кузовов для сборки.
4. **Скрытые коллизии данных:** несовпадение потерь рабочего времени с журналом аварий и дефицит месячного плана по моделям (4 800 авто при нормативе ≥5 500 авто).

**Решение Allur Digital Twin:**
Интерактивный цифровой двойник реального времени, сочетающий SCADA-мониторинг, вибродиагностику по промышленному стандарту **ISO 10816**, сценарный **What-If тренажер** и интеллектуального **AI Copilot** с системой аудита качества данных.

## 🤖 3. Искусственный интеллект и предиктивные модели

В соответствии с п. 6.4 Положения хакатона, проект использует гибридный AI-стек:

1. **Вибродиагностика главного Конвейера-03 по стандарту ISO 10816:**
   - Мониторинг среднеквадратичного значения (СКЗ) виброскорости привода.
   - Норма (Zone A/B): $\le 2.5$ мм/с. Предупреждение (Zone C): $4.5$ мм/с. Критический порог (Zone D): $6.0$ мм/с.
   - Прогнозирование усталостного растяжения тяговой цепи с расчетом наработки подшипниковых узлов.
   - **Эффект:** превентивная замена дефектного звена за 12 минут в пересменку вместо 55 минут аварийного останова.

2. **Физико-статистическая модель микроклимата окрасочной камеры:**
   - Многопараметрический контроль сушильной печи: температура сушки ($140 \pm 2^\circ\text{C}$), вязкость эмали (20–22 сек по ВЗ-4), относительная влажность ($60\text{--}70\%$) и перепад давления фильтра.
   - Расчет риска дефектов «шагрень» и потеков эмали до выхода кузова из камеры.
   - **Эффект:** снижение брака с 5.2% до 1.3% (спасение 6 кузовов за смену от повторного перекраса).

3. **Explainable AI Copilot & AI Evaluation Harness:**
   - Контекстный диалоговый ассистент с привязкой к технологическим участкам, выявлением корневых причин (Root Cause Analysis) и формированием наряд-заказов ремонтным бригадам.
   - **Evaluation Harness:** встроенный тестовый бенчмарк (8 калиброванных промышленных сценариев, точность 100%, F1-score 1.0, инференс <0.1 мс).

4. **Использованные AI-инструменты при разработке (п. 6.4 Положения):**
   - Google Antigravity / Claude 3.5 Sonnet — архитектурное моделирование, синтез тестовых сценариев и рефакторинг сервисного слоя.

## 🛡️ 5. Условия внедрения и производственные ограничения (п. 6.2)

1. **Безостановочный монтаж:**
   - Сбор телеметрии осуществляется поверх существующей автоматики Siemens S7-1500 и роботов Fanuc/ABB через протокол **OPC UA / MQTT** без изменения управляющей логики ПЛК.
2. **Пилотный контур:**
   - Срок развертывания пилота — 4 недели (линии Окраски и Сборки).
3. **Производственные ограничения:**
   - Точность вибродиагностики требует калибровки базового шума несущих металлоконструкций цеха сборки.
   - Термодинамическая модель окраски требует сезонной калибровки (зима/лето) для учета влажности наружного воздуха г. Костанай.

## 🛠️ 6. Технологический стек и перечень библиотек (п. 5.8)

### Backend:
- `Python 3.12` — базовая среда исполнения
- `FastAPI 0.142.2` — асинхронный REST API фреймворк
- `Uvicorn 0.54.0` — ASGI-сервер
- `Pydantic v2` — строгая типизация и валидация телеметрии
- `Supabase 2.32.0` — реляционное хранилище производственных записей

### Frontend:
- `React 18` + `Vite` — сборка и реактивный интерфейс
- `TailwindCSS` — дизайн-система и адаптивная верстка
- `Recharts` — визуализация почасовых трендов выпуска и простоев

## 🚀 7. Локальный запуск

### 1. Бэкенд:
```bash
cd backend
python -m venv venv
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
Swagger документация доступна по адресу: `http://localhost:8000/docs`

### 2. Запуск стресс-теста решения:
```bash
cd backend
python scripts/stress_test_case.py
```

### 3. Фронтенд:
```bash
cd front/allur-twin
npm install
npm run dev
```
Интерфейс доступен по адресу: `http://localhost:5173`
